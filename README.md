# ดูเอกสาร A/B เทียบกัน

หน้าเว็บไฟล์เดียว (`index.html`) สำหรับเปิดเอกสารสองไฟล์เทียบกันแบบคู่ขนาน
รองรับ PDF, Word (.docx), รูปภาพ และไฟล์ข้อความ ไฟล์ละไม่เกิน 100 MB พร้อมเลื่อนพร้อมกันและซูมแยกฝั่ง

## วิธีใช้
- เปิด `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages
- ลากไฟล์มาวางที่ฝั่ง A และ B

## ข้อควรรู้เมื่อใช้นอก claude.ai
- ไฟล์ที่ใส่จะถูกเก็บในเบราว์เซอร์ของเครื่องนั้น (IndexedDB) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ และคนอื่นจะไม่เห็นไฟล์เดียวกัน
- ช่อง "สรุปความแตกต่าง" และการแชร์เอกสารให้ทุกคนใช้ได้เฉพาะเมื่อเปิดจาก claude.ai เท่านั้น
- ต้องต่ออินเทอร์เน็ตเพื่อโหลดไลบรารี pdf.js, docx-preview และฟอนต์จาก CDN

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้
2. ไปที่ Settings > Pages เลือก Deploy from a branch, branch `main`, โฟลเดอร์ `/ (root)`
3. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
